============================================================
2. اجرای ربات
============================================================

محیط مجازی Python:

venv


برای اجرای ربات:

venv\Scripts\python.exe main.py


اگر ربات در حال اجرا باشد CMD باز می‌ماند.


برای متوقف کردن:

Ctrl + C


بعد از تغییر کد بهتر است اول Syntax را تست کنم.


مثال:

venv\Scripts\python.exe -m py_compile main.py


برای یک فایل:

venv\Scripts\python.exe -m py_compile app\bot\alert_handlers.py


اگر هیچ خروجی نداد:

Syntax OK است.


اگر Error داد:

ربات را اجرا نکن.
اول Error را اصلاح کن.

4. main.py چیست؟
============================================================

کارهای اصلی main.py:

- ساخت Telegram Application
- اتصال BOT_TOKEN
- ثبت Handlerها
- اجرای /start
- وصل کردن Callbackها
- وصل کردن Message Handler
- روشن کردن Workerها
- اجرای run_polling


مثلاً:

Alert Handler

Language Handler

همگی در نهایت باید به Application وصل شوند.


قانون مهم:

تا جای ممکن منطق سنگین داخل main.py ننویسم.

main.py باید بیشتر نقش:

STARTER + ROUTER

داشته باشد.


اگر یک قابلیت جدید ساختم:

مثلاً News

بهتر است:

app/bot/news_handlers.py

بسازم و فقط اتصالش را در main انجام دهم.
